## Herramientas

Las escribí porque las necesitaba en mi trabajo. Las tres tienen tests y se usan
desde línea de comandos.

| | Qué hace |
|---|---|
| [**seo-audit**](https://github.com/angelmunizpedraza/seo-audit) | Rastrea un sitio y devuelve incidencias de indexación, contenido, rendimiento y datos estructurados, ordenadas por gravedad. |
| [**geo-check**](https://github.com/angelmunizpedraza/geo-check) | Comprueba si un sitio está preparado para ChatGPT, Perplexity y AI Overviews: acceso de bots de IA, `llms.txt`, JSON-LD y legibilidad. |
| [**ga4-report**](https://github.com/angelmunizpedraza/ga4-report) | Informe de tráfico orgánico desde la API de GA4 con comparación de periodos y alertas de landing pages, listo para n8n. |
